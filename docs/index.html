afx

afx is a fast, local coding agent for the terminal. One native Zig binary reads and edits repositories, runs programs, searches the web, talks to model providers, uses language servers and debuggers, and delegates bounded work to focused task agents.

Development release 0.0.5. macOS and Linux, Zig 0.16, Apache-2.0 licensed.

Properties

  • One native afx binary with no application framework.
  • Compact terminal scrollback with bounded OMP-style cards for commands, edits, searches, tasks, and debugger work.
  • Saved sessions, plans, checkpoints, todos, branches, and child-agent state.
  • Stable and development updates served only from GitHub Releases.
