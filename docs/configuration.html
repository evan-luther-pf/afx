afx > Configuration

Configuration

afx keeps private user state separate from project defaults.

PathPurpose
~/.afx/settings.jsonUser and workspace preferences
.afx.jsonSafe project defaults committed with a repository
~/.afx/mcp.jsonMCP server configuration
~/.afx/skills/Personal managed skills
.afx/skills/Project skills
~/.afx/agents/Personal task-agent profiles
.afx/agents/Project task-agent profiles
~/.afx/sessions/Saved sessions and runtime state

Precedence

  1. Environment variables
  2. Workspace overrides in ~/.afx/settings.json
  3. Global values in ~/.afx/settings.json
  4. Project defaults in .afx.json
  5. Built-in defaults

Project configuration accepts only repository-safe defaults. Provider keys, private permissions, runtime state, and personal interface preferences remain in the user profile.

Inspect the active state

afx status
afx status --json
afx doctor --json

Inside the terminal interface, use /settings for display, model, permission, and session preferences.
