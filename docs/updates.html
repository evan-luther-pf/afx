Updates and troubleshooting

Update

afx checks GitHub Releases. Stable builds use versioned releases. Development builds use the moving dev prerelease.

afx upgrade
afx upgrade --channel stable
afx upgrade --channel dev

Automatic checks download a verified archive in the background. When the footer reports that an update is installed, press Ctrl+G to reload the current executable.

Common problems

afx cannot find a provider.
Run afx providers, then sign in or add a provider API key.
A command needs approval.
Review the exact action in the permission screen. Approval applies only to that action.
The interface looks wrong after an update.
Run afx --version, close old terminal sessions, and launch the installed binary again.
A saved session will not open.
Check whether the same session is open in another terminal. Run afx sessions to inspect available sessions.
I found a bug.
Open a GitHub issue. Include the afx version, operating system, and smallest reproduction.

Remove afx

Remove the binary from your PATH. Settings, credentials, and saved sessions remain under ~/.afx/; remove that directory separately only if you intend to delete them.
