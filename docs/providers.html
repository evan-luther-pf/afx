afx > Providers and models

Providers and models

afx supports subscription sign-in, direct API keys, AI Gateway, and OpenAI-compatible endpoints. The available model list follows the credentials configured on the current machine.

Manage providers

afx providers
afx login codex
afx login google
afx logout codex

Inside the terminal interface, use /providers to add, remove, or reauthenticate a provider. Use /model to select an available model and reasoning effort.

Credential sources

Subscription sign-in
Codex, Google, and supported provider sessions use their native OAuth flows.
API keys
Provider-scoped keys can be entered through provider management or supplied through documented environment variables.
AI Gateway
A Gateway key or eligible Vercel session provides access to the configured Gateway catalog.

afx keeps provider credentials isolated. A key selected for one provider is not silently reused for another. Replay-safe authentication or quota failures can rotate to another configured source while preserving the failed source for diagnostics.

Web search models

Native Gemini grounding defaults to gemini-2.5-flash. Native Anthropic search defaults to claude-haiku-4-5. Gateway search defaults to google/gemini-2.5-flash. Search cards display the provider, model, sources, and token usage.
