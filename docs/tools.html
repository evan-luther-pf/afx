afx > Tools

Tools

afx includes the development tools needed to inspect, change, and verify a repository. Tool availability follows the current mode, agent role, and project policy.

Files and terminals

File tools read bounded ranges, list directories, search names and contents, and perform exact edits, writes, copies, moves, and deletion. Terminal tools run captured commands or keep persistent processes alive for later input and output.

Common reads remain compact. Commands and mutations use bounded visual cards. Long results can be recovered through stable result handles.

Language servers

The lsp tool uses project language servers for diagnostics, definitions, type definitions, implementations, references, hover, symbols, renames, file renames, and code actions. Symbol-aware renames update real references instead of relying on text replacement.

Debug adapters

The debug tool drives one native Debug Adapter Protocol session. It supports launch and attach, breakpoints, stepping, threads, stacks, scopes, variables, evaluation, disassembly, memory access, modules, source discovery, and deterministic termination.

Web research

web_search queries the current public web and returns an answer, bounded sources, provider model, and usage. web_fetch reads one known public URL as untrusted reference material. Search results should be cited with links.

MCP, skills, and images

afx discovers configured MCP tools without loading every schema into the main prompt. Exact tools can then be selected and called. MCP resources, prompts, and argument completion use stable server-qualified identities.

Skills provide reusable instructions. Vision inspects user-authorized images. Memory stores explicit user preferences. Todos and checkpoints preserve durable work state.
