Sessions, plans, and task agents

Sessions

Interactive work is saved automatically unless an unsaved run is requested. List or resume saved work with:

afx sessions
afx session resume last
afx session resume --id <id>

Each session records its workspace, messages, tool activity, branches, todos, checkpoints, and child-agent relationships. Session state lives under ~/.afx/sessions/.

Plans and checkpoints

/plan limits the turn to inspection and planning, then presents the result for review before implementation. A checkpoint marks the start of an investigation. Rewind replaces exploratory conversation after that point with one concise findings report without changing files or processes.

Todos

The todo tool keeps a phased task list in the saved session. Work can be pending, active, completed, blocked, dropped, or appended. An unfinished list remains visible until every task is closed.

Task agents

The task tool dispatches substantial independent work to focused roles. The parent owns decomposition, shared contracts, integration, and final verification. Child agents can coordinate through hub when their work shares an orchestration tree.

Built-in roles cover investigation, design, review, security, library research, mechanical work, and general implementation. Project roles live in .afx/agents/; personal roles live in ~/.afx/agents/.

Use the standalone word orchestrate in a prompt when you explicitly want substantial independent slices dispatched together.
