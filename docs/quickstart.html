Install and quickstart

afx publishes native archives for macOS and Linux. Current development release: 0.0.10.

Install

Download the archive for your platform from the latest GitHub release. Extract it and place the binary on your PATH:

mkdir -p ~/.local/bin
mv afx ~/.local/bin/afx
afx --version

Build from source with Zig 0.16 or newer:

git clone https://github.com/evan-luther-pf/afx.git
cd afx
zig build -Doptimize=ReleaseSafe
./zig-out/bin/afx

Authenticate

Sign in with a supported subscription:

afx login codex
afx login google

Or manage provider API keys:

afx providers

Private credentials and settings live under ~/.afx/. The platform credential store is used where supported.

Start afx

Run afx from the repository the agent may access:

cd path/to/repository
afx

Open the model selector with /model. Open provider management with /providers. Ask for the outcome you want in ordinary language.

Other modes

afx ask "..." runs one noninteractive request. afx acp starts an Agent Client Protocol server over standard input and output. afx status --json reports the active configuration.
