# Product Roadmap

Current priorities:

1. Define first-class user plugins and scripting beyond skills, agent profiles, and MCP; users must be able to extend afx without rebuilding the binary.
2. Close remaining role-policy edges for selectively allowed MCP tools.
3. Add optional AFX browser or AST capabilities only when a concrete workflow requires them; native LSP is now built in.
4. Push a feature branch and pass the repository's full multi-platform CI before release.

The roadmap is intentionally short. New priorities belong here only while they describe current direction.
