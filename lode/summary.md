# Project Summary

afx is a terminal-first orchestration coding-agent harness written in Zig. It combines native development tools, MCP and skills, durable sessions, role-based task agents, same-tree `hub` messaging, session-persistent `todo` state, custom agent profiles, compact orchestration guidance, and enforced role tool/spawn policies.

See [AFX architecture](afx/summary.md), [project terminology](terminology.md), and [engineering practices](practices.md).
